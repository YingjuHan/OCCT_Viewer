# Enumeration: ShapeObjectSelMode

ShapeObjectSelMode represents selection mode of [InteractiveShape](../classes/InteractiveShape.md), from `InteractiveShapeSelMode`.
It is defined as a bitmask to support several active selection mode simultaneously in the viewer.
