# SCRWMed模块分析

## 概述

SCRWMed模块是专门用于读取MED格式文件的模块。MED（Model for Exchange of Data）是由EDF（法国电力集团）开发的一种用于存储和交换科学计算数据的文件格式，主要用于有限元分析等CAE应用中。

## SCRWMedReader.h

### 类定义

[SCRWMedReader]类是MED文件读取器的主要类，提供以下功能：

1. **读取MED文件**：将MED文件读取并转换为内部的网格数据结构
2. **支持映射文件**：可选的JSON映射文件用于组合MED字段的特定组件
3. **状态管理**：提供读取操作的状态信息

### 主要成员

```cpp
enum class ReaderStatus { Done = 0, MissingFields, NotDone = 100 };
```
读取器状态枚举，表示读取操作的结果状态。

```cpp
bool Perform(const std::string& theFilePath,
             const std::string& theMappingFilePath,
             const std::string& theArtifactFilePath);
```
主要的执行函数，用于读取MED文件并处理为网格数据。

```cpp
const std::vector<Handle(SCRWCae::MeshData)>& Meshes() const { return myOutMeshes; }
```

## SCRWMedReader.cpp

这是SCRWMed模块的核心实现文件，代码量很大（超过1800行），包含了大量的MED文件处理逻辑。

### 主要功能

#### 1. MED文件读取
- 读取MED文件中的网格几何信息（节点和单元）
- 读取MED文件中的场数据（节点场和单元节点场）
- 支持MED v3+格式

#### 2. 数据结构转换
- 将MED格式的数据转换为内部的`SCRWCae::MeshData`结构
- 处理不同类型的网格单元（三角形、四边形、四面体、六面体等）
- 节点索引转换（MED和内部表示之间的差异）

#### 3. 字段处理
- 支持标量、向量、张量等不同类型的场数据
- 处理时间步数据
- 支持通过映射文件自定义字段组合

#### 4. 映射文件支持
- 可选的JSON映射文件用于自定义字段处理
- 支持生成artifact文件记录未匹配的字段

### 关键数据结构

#### MEDFieldInfo
存储MED文件中字段的信息：
- 网格名称
- 字段名称
- 字段类型
- 时间单位
- 时间步数
- 组件数量和名称

#### NFInfo
新字段信息，用于处理映射文件中的字段定义：
- 字段名称和描述
- 组件索引和单位
- 字段类型
- 时间步描述等

#### MeshElementsInfo
网格元素信息：
- 几何类型
- 元素数量
- 偏移量

### 主要处理流程

1. **文件打开**：使用MED库打开MED文件
2. **网格几何读取**：
   - 读取节点坐标
   - 读取单元连接信息
   - 转换为内部网格数据结构
3. **字段读取**：
   - 读取字段元信息
   - 处理映射文件（如果提供）
   - 读取字段数据
   - 转换为内部属性数据结构
4. **数据后处理**：
   - 更新属性范围
   - 处理临时文件存储（如果启用）

### 特殊处理

#### 节点索引转换
由于MED格式和内部表示在某些单元类型上的节点顺序不同，代码中实现了专门的索引转换函数`ConvertM2MNodeIndex`。

#### 映射文件支持
通过JSON映射文件可以：
- 自定义字段组合
- 指定字段单位
- 控制字段处理方式

#### 内存优化
支持将处理后的属性数据转储到临时文件并卸载，以节省内存。

## 依赖关系

### 内部依赖
- [SCRWCae]模块：网格数据结构和相关处理功能
- `SCRWBase`模块：基础工具类

### 外部依赖
- MED库：用于读取MED格式文件
- OpenCASCADE：几何和数学相关功能

## 编译配置

CMakeLists.txt显示该模块：
- 依赖于SCRWBase和SCRWCae模块
- 可选择性地链接MEDFILE库
- 链接必要的OpenCASCADE库

## 总结

SCRWMed模块是一个功能完整的MED文件读取器，具有以下特点：

1. **完整的MED支持**：支持MED v3+格式，能够读取几何和场数据
2. **灵活的字段处理**：通过映射文件支持自定义字段处理
3. **内存优化**：支持属性数据的临时存储和卸载
4. **错误处理**：完善的错误处理和状态报告机制
5. **扩展性**：良好的架构设计，便于扩展新的功能

该模块是CAE数据可视化应用中处理MED格式数据的关键组件。
