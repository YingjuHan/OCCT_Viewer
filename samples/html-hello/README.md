Web 3D Viewer - static HTML page Hello-World sample
==================

## Description

This HTML sample demonstrates basic 3D Viewer setup in static HTML page.

## Project setup

### Be sure that you have viewer package data, please check path ("../../wasm32" and "../../wasm32-pthread") in tsconfig.json.

### Go to project install directory and run simple http server (you should have installed python3)
It will run http server on http://localhost:5500. You can specify another port as first argument in next script:
```
python3 scripts/server.py 5500
```

### Open in browser
```
http://localhost:5500/samples/html-hello/index.html
```
